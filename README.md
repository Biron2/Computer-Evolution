# Computer Evolution

A casual WebGL clicker game developed with Unity for Yandex Games.

## About

Computer Evolution was my first game published on Yandex Games and the starting point of a series of evolution-themed clicker games.

I developed the game from scratch in just 3 days. It also became my most commercially successful project among these games.

The project gave me practical experience in Unity WebGL development, rapid prototyping, and publishing browser games.

## Project Details

- **Engine:** Unity
- **Platform:** WebGL
- **Genre:** Clicker / Idle
- **Distribution:** Yandex Games
- **Development Time:** 3 days
- **Status:** Archived
